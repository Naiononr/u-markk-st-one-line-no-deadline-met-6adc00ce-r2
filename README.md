A deterministic, stdlib-only Python program that writes one single-line joke excusing a missed deadline — a confession that the work was left with tomorrow, who turned out to be a very convincing liar — to `/output/entry.txt`, satisfying the gate of 1–200 UTF-8 characters on a single line.

## Run

```sh
python3 -P -s main.py
```

This writes the line to `/output/entry.txt` (set `OUTPUT_DIR` to override the output directory for local runs). Repeated runs produce byte-identical output.
